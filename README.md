# 🐕 Hound Express - Frontend V1

## 📖 Description
Hound Express ("El mensajero fiel") is a web interface for managing courier shipment guides, developed as part of the Fullstack with Python course (EBAC). From a single page, users can register new guides (guide number, origin, destination, recipient, creation date and initial status), review a general status summary, browse the list of guides, and open the status history of each one. The forms use Bootstrap validation, and the interface is built with plain HTML, SCSS and JavaScript.

## 🛠️ Technologies used
- **Main language:** JavaScript
- **Markup & styling:** HTML5, SCSS / CSS
- **Frameworks & libraries:** Bootstrap 5.3 (via CDN)
- **Database:** None in this repository
- **Resources:** Google Fonts (Open Sans), Flaticon UIcons

## 📂 Project structure
- `index.html` — Main page (guide registration, general status, guide list and history panel)
- `js/` — Application logic (`script.js`)
- `scss/` — Stylesheets
- `css/` — Compiled styles
- `img/` — Logo and icons

## 🚀 Getting started

### Prerequisites
- A modern web browser
- An internet connection (Bootstrap, Google Fonts and Flaticon are loaded from CDNs)
- (Optional) A local static server such as the VS Code *Live Server* extension

### Installation
```bash
git clone https://github.com/ResergeDXVS/Hound_Express_Project.git
cd Hound_Express_Project
```

### Run
Open `index.html` directly in your browser, or serve the folder with a local server:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).
